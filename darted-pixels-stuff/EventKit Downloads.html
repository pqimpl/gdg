Laptop setup

Install EventKit at home, before the event.

Download it for your laptop, sign in with the Google account you RSVP'd with, and click Set up my laptop. Do this before you arrive so you are ready when the event starts.

Set up in four steps

  1. Download the file for your laptop

    Use the Windows or Linux button above. The file is large, so start it on a good connection.

  2. Install it

    Windows

    Run the installer you downloaded. If Windows shows "Windows protected your PC", click More info, then Run anyway.

    Linux

    Open a terminal in the folder with the download and run:

    chmod +x EventKit-0.1.3-x86_64.AppImage
./EventKit-0.1.3-x86_64.AppImage

    If it says "AppImages require FUSE", install FUSE 2: the package is libfuse2 on most distros and fuse2 on Arch.

  3. Sign in with Google

    Use the same Google account you RSVP'd with. A different account will not match your registration.

  4. Click Set up my laptop

    EventKit does the rest. Once it finishes, your laptop is ready for the event.
